# Agent Instructions

## Project Context

Slovarik is a personal vocabulary learning app.

Read `README.md` to understand the project goals, features, and tech stack.

## Development Guidelines

- Follow the existing project structure and coding conventions.
- Keep the code simple, readable, and maintainable.
- Avoid unnecessary abstractions and complexity.
- Do not add new dependencies unless they are needed for the current task.
- Use TypeScript for both frontend and backend.
- Do not implement features that were not requested.

## Workflow

- Review the relevant code before making changes.
- Ask for clarification if requirements are unclear.
- Make small, focused changes.
- Run available checks after making changes.
- Report what was changed and mention any issues or limitations.
